## ✨ 这是什么

**OpenGEO** 是一个聚焦 **GEO（Generative Engine Optimization，生成式引擎优化）** 的开放知识库。

当越来越多的用户不再翻页点击搜索结果，而是直接向 ChatGPT、Perplexity、Gemini、Claude、Kimi、DeepSeek、豆包等生成式引擎提问，**「被 AI 引用」正在取代「被搜索排名」，成为新的流量与信任入口。**

OpenGEO 系统整理 GEO 的理论、机制、概念、方法、工具、案例与行业动态，并持续收录全球范围内的学术论文与行业报告，目标是：

- 📐 建立一套**开放、可复用、可验证**的 GEO 知识体系；
- 🔬 用**学术研究 + 行业报告 + 一线实践**三条证据链支撑每一个结论；
- 🌏 为中文与全球的创作者、品牌方、研究者提供一个**免费、可自由引用**的公共知识底座。

> ### 💡 一句话理解
>
> **SEO 让人搜到你，GEO 让 AI 推荐你。**

## 🧭 什么是 GEO

**GEO（生成式引擎优化）** 是面向 AI 回答引擎的内容与信源优化方法：通过结构化内容、权威信源建设与语义布局，让品牌、产品与观点在生成式引擎的回答中被优先引用、准确呈现。

| 维度 | 传统 SEO | GEO 生成式引擎优化 |
| :--- | :--- | :--- |
| **流量入口** | 搜索引擎结果页（蓝色链接列表） | AI 对话式回答（直接生成的答案） |
| **用户行为** | 输入关键词 → 逐条点击比对 | 直接提问 → 采信 AI 汇总后的答案 |
| **竞争位置** | 一页可容纳 10 个自然结果 | 一次回答通常只引用 **2–5 个信源**，位置极度稀缺 |
| **优化对象** | 关键词、外链、页面结构、权重 | 语义结构、可引用片段、权威信源、实体认知 |
| **结果形态** | 获得点击与访问 | 被 AI **写进答案**、被直接复述与推荐 |
| **衡量方式** | 排名、点击率、自然流量 | AI 引用率、提及准确率、信源占位 |

GEO 并不取代 SEO，而是在「答案即入口」的新分发逻辑下，成为品牌与内容必须补上的一课。

## 🔄 内容更新机制

OpenGEO 采用「**一处维护、多端同步**」的开放流水线：

1. **采集与编目**：新内容先在在线知识库中完成分级、标签、一句话总结与原文链接；
2. **审校与版本化**：通过统一台账进行审校、编号与版本管理，保证每条记录可追溯；
3. **公开发布**：审校后的内容同步到 GitHub 仓库与项目官网，GitHub 承担公开镜像、版本历史与社区协作；
4. **持续迭代**：内容更新会递增版本号，撤稿与勘误同样留痕，确保引用方始终拿到可信版本。

> 在线知识库是阅读体验最完整的入口；GitHub 适合追踪变更、引用原文与参与协作。

## 🤝 参与贡献

OpenGEO 以开放为原则，欢迎通过 **Issue** 与 **Pull Request** 参与：

- **推荐资料**：提交值得收录的论文、报告或案例（请附公开来源链接）；
- **补充词条**：完善概念层、机制层的术语解释；
- **贡献案例**：分享你自己的 GEO 实践与数据观察；
- **勘误纠错**：指出失效链接、事实错误或标注不当的内容。

收录标准：**公开可溯源、分级清晰、客观中立**；所有外部资料必须保留原始出处，商业立场材料需显式标注。
