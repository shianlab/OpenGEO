## ✨ 이것은 무엇인가요?

**OpenGEO**는 **GEO(Generative Engine Optimization, 생성형 엔진 최적화)**에 집중한 공개 지식 베이스입니다.

사용자가 검색 결과 페이지를 일일이 클릭하는 대신 ChatGPT, Perplexity, Gemini, Claude, Kimi, DeepSeek, 더우반(豆包) 등 생성형 엔진에 직접 질문하는 일이 늘면서, **"AI에 인용되는 것"이 "검색 순위에 오르는 것"을 대체하는 새로운 트래픽과 신뢰의 관문**이 되고 있습니다.

OpenGEO는 GEO의 이론·메커니즘·개념·방법·도구·사례·산업 동향을 체계적으로 정리하고, 전 세계의 학술 논문과 산업 리포트를 지속적으로 수록합니다. 우리의 목표:

- 📐 **개방되고, 재사용 가능하며, 검증 가능한** GEO 지식 체계를 구축하는 것;
- 🔬 모든 결론을 **학술 연구·산업 리포트·현장 실천**이라는 세 가지 증거 사슬로 뒷받침하는 것;
- 🌏 중국어권과 전 세계의 크리에이터, 브랜드, 연구자를 위한 **무료로 자유롭게 인용 가능한** 공공 지식 기반을 제공하는 것.

> ### 💡 한 문장으로 이해하기
>
> **SEO는 사람이 나를 찾게 만들고, GEO는 AI가 나를 추천하게 만듭니다.**

## 🧭 GEO란 무엇인가

**GEO(생성형 엔진 최적화)**는 AI 답변 엔진을 대상으로 콘텐츠와 정보 소스를 최적화하는 실천입니다. 구조화된 콘텐츠, 권위 있는 정보 소스 구축, 의미론적 배치를 통해 브랜드·제품·관점이 생성형 답변에서 정확하고 눈에 띄게 인용될 확률을 높입니다.

| 관점 | 전통적 SEO | GEO(생성형 엔진 최적화) |
| :--- | :--- | :--- |
| **유입 관문** | 검색엔진 결과 페이지(파란 링크 목록) | AI 대화형 답변(즉시 생성되는 답) |
| **사용자 행동** | 키워드 입력 → 결과를 클릭해 비교 | 질문 → AI가 종합한 답을 그대로 신뢰 |
| **노출 자리** | 페이지당 약 10개의 자연 검색 결과 | 한 번의 답변에 인용되는 소스는 보통 **2~5개**로 매우 희소 |
| **최적화 대상** | 키워드, 백링크, 페이지 구조, 권위도 | 의미 구조, 인용 가능한 스니펫, 권위 소스, 엔티티 인지 |
| **결과 형태** | 클릭과 방문 확보 | AI 답변에 **직접 작성**되어 그대로 반복·추천됨 |
| **측정 지표** | 순위, CTR, 자연 유입 | AI 인용률, 언급 정확도, 소스 점유율 |

GEO는 SEO를 대체하는 것이 아닙니다. "답 자체가 관문"이 되는 새로운 유통 논리 아래서 브랜드와 콘텐츠가 반드시 갖춰야 할 다음 레이어입니다.

## 🔄 콘텐츠 업데이트 방식

OpenGEO는 **"한 곳에서 유지보수하고, 모든 곳에 공개"**하는 파이프라인을 따릅니다:

1. **수집과 목록화** — 새 콘텐츠는 온라인 지식 베이스에서 등급·태그·한 줄 요약·원문 링크를 부여;
2. **검토와 버전 관리** — 통합 대장에서 리뷰, 채번, 버전 관리를 거쳐 모든 기록을 추적 가능하게 유지;
3. **공개 발행** — 검토를 마친 콘텐츠를 GitHub 저장소와 프로젝트 공식 사이트에 동기화. GitHub는 공개 미러·변경 이력·커뮤니티 협업의 장;
4. **지속 반복** — 갱신 시 버전 번호를 올리고, 철회와 정정도 이력을 남겨 인용자가 항상 신뢰 가능한 버전을 받도록 보장합니다.

> 가장 완성도 높은 독서 경험은 온라인 지식 베이스에 있습니다. 변경 추적, 원문 인용, 협업에는 GitHub가 적합합니다.

## 🤝 기여하기

OpenGEO는 개방 원칙으로 운영되며, **Issue**와 **Pull Request**를 통한 기여를 환영합니다:

- **자료 추천** — 수록할 만한 논문·리포트·사례(공개 출처 링크 필수);
- **항목 보강** — 개념·메커니즘 계층의 설명 개선;
- **사례 공유** — 본인의 GEO 실천과 데이터 관찰;
- **오류 정정** — 깨진 링크, 사실 오류, 잘못된 라벨 신고.

수록 기준: **공개되고 추적 가능한 출처, 명확한 등급, 객관적·중립적 태도**. 모든 외부 자료는 반드시 원출처를 남기고, 상업적 입장을 담은 자료는 그 사실을 명시해야 합니다.
