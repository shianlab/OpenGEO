## ✨ これは何ですか？

**OpenGEO** は、**GEO（Generative Engine Optimization、生成エンジン最適化）** に特化したオープンナレッジベースです。

検索結果ページをクリックして回る代わりに、ChatGPT、Perplexity、Gemini、Claude、Kimi、DeepSeek、豆包（Doubao）などの生成エンジンに直接質問するユーザーが増える中で、**「AI に引用されること」が、「検索で上位に表示されること」に代わる新しい流入と信頼の入口**になりつつあります。

OpenGEO は、GEO の理論・仕組み・概念・方法・ツール・事例・業界動向を体系的に整理し、世界中の学術論文と業界レポートを継続的に収録します。私たちのゴール：

- 📐 **オープンで、再利用可能で、検証可能な** GEO 知識体系をつくること；
- 🔬 すべての結論を「**学術研究・業界レポート・現場の実践**」という 3 本の証拠の鎖で支えること；
- 🌏 中国語圏と世界のクリエイター、ブランド、研究者のための、**無料で自由に引用できる**公共の知識基盤を提供すること。

> ### 💡 一言でいうと
>
> **SEO は「人に見つけてもらう」もの。GEO は「AI に推薦してもらう」もの。**

## 🧭 GEO とは何か

**GEO（生成エンジン最適化）** は、AI 回答エンジンに向けてコンテンツと情報ソースを最適化する実践です。構造化されたコンテンツ、権威ある情報源の構築、意味的な配置を通じて、ブランド・製品・見解が生成回答の中で正確かつ目立つ形で引用される確率を高めます。

| 観点 | 従来の SEO | GEO（生成エンジン最適化） |
| :--- | :--- | :--- |
| **入口** | 検索エンジン結果ページ（青いリンク一覧） | AI の対話型回答（その場で生成される答え） |
| **ユーザー行動** | キーワード入力 → 結果をクリックして比較 | 質問 → AI が統合した答えをそのまま信頼 |
| **枠の数** | 1 ページに約 10 件の自然検索結果 | 1 回の回答で引用される情報源は通常 **2〜5 件**と極めて希少 |
| **最適化対象** | キーワード、被リンク、ページ構造、権威度 | 意味構造、引用しやすい断片、権威ソース、実体（エンティティ）認知 |
| **成果の形** | クリックと訪問を獲得 | AI の答えに**書き込まれ**、そのまま復唱・推奨される |
| **測定指標** | 順位、CTR、オーガニック流入 | AI 引用率、言及の正確性、情報源シェア |

GEO は SEO を置き換えるものではありません。「答えそのものが入口」となる新しい配布ロジックの下で、ブランドとコンテンツが必ず備えるべき次のレイヤーです。

## 🔄 コンテンツ更新の仕組み

OpenGEO は「**1 か所で保守し、あらゆる場所へ公開**」するパイプラインを採用しています：

1. **収集と目録化** — 新しいコンテンツはオンライン知識ベースで等級付け・タグ付け・一言要約・原文リンクの付与を実施；
2. **校閲とバージョン管理** — 統一台帳でレビュー、採番、バージョン管理を行い、すべての記録を追跡可能に；
3. **公開** — 校閲済みコンテンツを GitHub リポジトリとプロジェクト公式サイトへ同期。GitHub は公開ミラー・変更履歴・コミュニティ協働の場；
4. **継続的反復** — 更新時はバージョン番号を上げ、撤回や訂正も記録を残すことで、引用者が常に信頼できる版を取得できるようにします。

> 読書体験が最も充実し、更新が最も速いのは Feishu のオンライン知識ベースです。変更の追跡、原文の引用、協働には GitHub が適しています。

## 🤝 貢献について

OpenGEO はオープンに運営されています。**Issue** と **Pull Request** での貢献を歓迎します：

- **資料の推薦** — 収録に値する論文・レポート・事例（公開ソースのリンク必須）；
- **項目の拡充** — 概念・仕組みレイヤーの解説改善；
- **事例の共有** — ご自身の GEO 実践とデータ観察；
- **誤りの訂正** — リンク切れ、事実誤り、不適切なラベルの報告。

収録基準：**公開された追跡可能な出典があり、等級が明確で、客観的・中立的**であること。外部資料には必ず原出典を残し、商業的立場を含む資料はその旨を明示してください。
